# 🍔 Fast Food Infiniti

Website đặt đồ ăn nhanh online xây dựng bằng React + Node.js

## Công nghệ
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL

## Cài đặt
1. Clone repo
2. `npm install` (frontend)
3. `cd backend_fastfood && npm install`
4. Tạo file `.env` theo mẫu `.env.example`
5. `npm run dev` (chạy backend)
6. `npm run dev` (chạy frontend)
