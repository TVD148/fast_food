Khi muốn làm tính năng mới:

powershell
# Tạo nhánh tính năng từ develop
git checkout develop
git checkout -b feature/them-tinh-nang-moi
# ... làm code ...
# Nếu OK → merge vào develop
git checkout develop
git merge feature/them-tinh-nang-moi
# Nếu lỗi → bỏ nhánh đó đi, develop vẫn nguyên vẹn
git checkout develop
git branch -D feature/them-tinh-nang-moi
Khi develop ổn định → merge vào main để ra bản chính thức:

powershell
git checkout main
git merge develop
git push origin main

Bạn đang ở main và muốn merge code từ develop vào. Chạy:

powershell
# Kéo code mới nhất từ main
git pull origin main
# Merge develop vào main
git merge develop
# Đẩy lên GitHub
git push origin main
Sau khi merge xong, main sẽ có đầy đủ code từ develop (kể cả README đã update).

git add . (có dấu chấm) đã thêm tất cả file thay đổi rồi — không cần chỉ từng file!

powershell
git add .              # Dấu chấm = tất cả file thay đổi
git commit -m "..."
git push origin develop
Phân biệt:

Lệnh	Tác dụng
git add README.md	Chỉ thêm 1 file cụ thể
git add .	Thêm tất cả file đã sửa/thêm mới
git add src/	Thêm cả 1 thư mục
TIP

Muốn xem trước có những file nào sẽ được thêm, chạy git status — file màu đỏ là chưa add, màu xanh là đã add sẵn sàng commit.
